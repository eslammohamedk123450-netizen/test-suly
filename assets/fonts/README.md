# Font assets

The Flutter client bundles these fonts locally so Arabic and English typography remains consistent without remote font requests:

- **Tajawal** — Regular (400), Medium (500), Bold (700), and Black (900). Source: [Google Fonts — Tajawal](https://github.com/google/fonts/tree/main/ofl/tajawal).
- **Inter** — variable font (`opsz`, `wght`) from [Google Fonts — Inter](https://github.com/google/fonts/tree/main/ofl/inter).

The corresponding SIL Open Font License text is included beside each family in `Tajawal/OFL.txt` and `Inter/OFL.txt`. Preserve those license files when copying or redistributing the font assets.
