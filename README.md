# ChatGPT Clone (Next-Gen UI/UX & AI Workspace)

نسخة متطورة وتطابق كامل لتجربة **ChatGPT** الرسمية بتصميم وألوان وأدوات OpenAI الحديثة، مدعومة بنماذج ذكاء اصطناعي تفاعلية مع ميزات متقدمة ومساحات عمل احترافية.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. مساحة العمل التفاعلية (Canvas Workspace)
- مساحة جانبية جنبًا إلى جنب (Side-by-Side) لتحرير الأكواد والمستندات المطولة في نفس شاشة المحادثة.
- أدوات ذكاء اصطناعي سريعة بنقرة واحدة:
  - **تحسين الصياغة (Polish)**
  - **تقصير النص (Shorten)**
  - **توسيع الشرح (Lengthen)**
  - **فحص وإصلاح الأخطاء البرمجية (Fix Bugs)**
  - **إضافة تعليقات وتوثيق برمجي (Add Comments)**
- عدّاد أسطر، عدّاد كلمات، نسخ فوري، وتكبير الشاشة.

### 2. قائمة الأوامر الفورية (Slash Commands)
- كتابة `/` في حقل الإدخال تفتح قائمة تفاعلية بالأسهم والماوس:
  - `/image` — توليد وتصميم صور بالذكاء الاصطناعي
  - `/canvas` — فتح مساحة العمل البرمجية Canvas
  - `/code` — كتابة وتحليل أكواد برمجية
  - `/chart` — توليد رسوم بيانية تفاعلية (Bar, Line, Pie)
  - `/web` — تفعيل البحث في الويب
  - `/reason` — تفعيل وضع التفكير والتحليل المنطقي العميق (o1 / o3-mini)
  - `/summarize` — تلخيص نصوص أو ملفات

### 3. تنظيم المجلدات والمشاريع (Folders & Projects Management)
- إدارة متكاملة للمجلدات والمشاريع في الشريط الجانبي (Sidebar).
- إنشاء مجلدات جديدة، إعادة تسمية، ونقل المحادثات داخلها بسلاسة.
- طي وتوسيع المجلدات مع عدّاد المحادثات لكل مجلد.

### 4. سجل ذاكرة شات جي بي تي (ChatGPT Memory Log)
- تبويب مخصص في الإعدادات لإدارة ذاكرة النموذج (Memory).
- تفعيل/تعطيل الذاكرة الذكية بالكامل بنقرة واحدة.
- إضافة ذكريات وتفضيلات مخصصة يدويًا وحذفها.
- حقن الذاكرة تلقائيًا في توجيهات النظام (System Instructions) لتخصيص ردود الذكاء الاصطناعي.

### 5. مفتش المستندات وجداول البيانات التفاعلي (Document & CSV Inspector)
- فحص ملفات CSV وجداول البيانات في جدول تفاعلي منظم:
  - شريط بحث سريع لتصفية البيانات
  - تقسيم صفحات (Pagination)
  - ترويسات أعمدة وإحصائيات سريعة
- معاينة النصوص البرمجية والملفات النصية مع أرقام الأسطر.
- أزرار اقتراحات تحليل فورية بنقرة واحدة لإرسالها للشات.

### 6. بيئة تشغيل وتجربة الأكواد الحية (Code Sandbox & Visual Preview)
- تشغيل ومعاينة كود HTML و SVG و JavaScript و CSS مباشرة داخل المحادثة.
- توليد رسوم بيانية تفاعلية تدعم التفاعل والألوان المخصصة.

### 7. الوضع الصوتي المتقدم (Advanced Voice Mode)
- تفاعل صوتي فوري يشبه تجربة ChatGPT Voice مع تأثير الهالة الصوتية (Voice Orb).
- دعم الأصوات الخمسة الشهيرة: Breeze, Cove, Ember, Juniper, Sky.

### 8. النماذج والمتجر (Models & Custom GPTs Store)
- دعم GPT-4o، o1 (مع عرض خطوات التفكير Reasoning)، GPT-4o mini، و o3-mini.
- متجر Custom GPTs متكامل (DALL·E, Code Copilot, Writing Assistant, Data Analyst, etc.).

### 9. التصميم واللغات
- تطابق 100% مع واجهة OpenAI الداكنة (`#212121`, `#2f2f2f`) والفاتحة.
- دعم كامل للغة العربية (RTL) والإنجليزية (LTR).
- الوضع المؤقت (Temporary Chat)، البحث في المحادثات، ومشاركة الروابط.

## 🚀 التشغيل المحلي (Getting Started)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## 🛠 التقنيات المستخدمة (Tech Stack)
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Framer Motion.
- **Backend:** Node.js, Express, @google/genai SDK.
